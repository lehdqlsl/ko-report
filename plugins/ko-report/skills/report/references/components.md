# 원고 문법

원고는 마크다운이다. 아래 블록만 추가로 쓴다. HTML·style 은 쓰지 않는다.

## front matter

```
---
title: 주문 화면 개편 시험 결과            # 내용이 보이는 제목
type: qa                                    # progress·completion·qa·proposal·analysis·incident
audience: internal                          # internal·external
date: 2026-10-05
author: 플랫폼팀
basis: 스테이징 · v1.4.2 · 10/5 오전        # 수치의 기준
footer: (생략하면 date·author·basis)
---
```

## 절

`## 제목` 으로 나눈다. 번호는 빌드가 붙인다(원고에 번호를 써도 지운다). 첫 절은 결론으로 강조된다. `### 소제목` 은 절 안에서만.

## 숫자 타일

```
:::tiles
3.2초 → 0.4초 | 주문 목록 첫 화면(스테이징) | ok
2건 | 남은 결함 | warn
:::
```
`값 | 설명 | 색`. 색은 ok·warn·bad·info 중 하나 또는 생략. 2~4개.

## 상태 딱지

표 칸의 글자가 아래 단어와 **정확히 같으면** 색 딱지가 된다.

| 색 | 단어 |
|---|---|
| ok | 통과, 완료, 해결, 정상, 적용, 반영, 켜져 있음, 유지, 확인됨, 성공 |
| warn | 진행, 진행 중, 보류, 주의, 지연, 부분, 확인 필요, 예정, 재현 안 됨, 검토 |
| bad | 실패, 미해결, 문제, 위험, 중단, 오류, 차단, 누락 |
| info | 정보, 참고, 결정, 결정 필요, 제안 |

숫자만 있는 칸은 자동으로 오른쪽 정렬된다.

## 강조 상자

```
:::callout warn
한두 문장. 문서당 1~2개만.
:::
```

본문 중간 한 장은 일반 마크다운 `![설명](경로)` 도 된다.

## 결함 카드 (QA)

```
:::defect D-01 | 결제 완료 뒤 주문 목록 미갱신 | 해결
관찰: 실제로 본 것 그대로
기대: 원래 그래야 하는 것과 근거
증거: ![결제 완료 뒤 주문 목록](shots/order_list.png)
조치: 고친 내용·담당
:::
```
관찰·기대·증거는 필수(check.py 가 확인). 상태는 딱지 단어 중 하나.

## 막대 그래프

```
:::bars 화면 진입 시간(초, 스테이징)
주문 목록 | 0.4 | ok
주문 상세 | 0.6 | ok
정산 내역 | 2.1 | warn
:::
```
`라벨 | 값 | 색`. 값의 숫자로 길이를 맞춘다. 제목에 단위와 기준을 쓴다.
